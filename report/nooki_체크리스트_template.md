💡 왜? 광원에 따라 색 편향이 달라서 화이트밸런스/색상 정규화(Gray-World 등)를 쓸지 결정합니다.

💡 왜? 색온도가 섞여 있으면 HSV 색 기반 필터가 흔들리므로 색 보정이나 Color Jitter 증강의 범위를 정합니다.

1-4. 가구 밑 조도 (소파/침대 밑 중앙)

💡 왜? 저조도 노이즈가 얼마나 나오는지로 디노이즈 필터(Bilateral/NLM 등)와 CLAHE clipLimit의 강도를 정합니다.

1-5. 시간대별 조명 변화

💡 왜? 변화가 크면 고정 임계값 대신 적응형(히스토그램 기반) 밝기 보정이 필요합니다.

1-6. 직사광·강한 그림자
[ ] 없음 [ ] 창문 빛 줄무늬/블라인드 그림자 [ ] 가구 그림자 경계 뚜렷 [ ] 역광(창을 정면으로 봄)

💡 왜? 명암 경계가 강하면 전역 보정이 오히려 해롭기 때문에 지역 보정(CLAHE 타일 크기)과 그림자 억제 여부를 판단합니다.

1-7. 조명 깜빡임(Flicker) — 폰 카메라로 조명을 비췄을 때

💡 왜? 깜빡임이 있으면 노출 시간 동기화나 프레임 간 밝기 평활화(temporal normalization) 같은 전처리가 필요합니다.

2. 바닥 특성 (배경)
2-1. 바닥 재질
[ ] 강화마루/원목 [ ] PVC 장판 [ ] 무광 타일 [ ] 유광 타일/대리석 [ ] 얇은 카펫/러그 [ ] 콘크리트/에폭시

💡 왜? 재질마다 텍스처와 반사가 달라서 배경 억제 방식(블러, 텍스처 필터)을 고르는 기준이 됩니다.

2-2. 바닥 광택(반사) — 손전등을 비스듬히 비춰 확인
[ ] 무광(반사 없음) [ ] 반광(은은한 반사) [ ] 고광택(조명·물체가 비침)

💡 왜? 정반사 하이라이트가 흰색·금속 물품과 헷갈리므로 하이라이트 억제, 편광 필터, LED 각도 조정이 필요한지 판단합니다.

2-3. 바닥 패턴 복잡도
[ ] 무지(단색) [ ] 약한 나뭇결 [ ] 강한 나뭇결/줄눈 [ ] 체크·기하학 무늬 [ ] 복잡한 카펫 무늬

💡 왜? 패턴이 복잡할수록 작은 물체가 배경 고주파에 묻히므로 엣지 강화를 피하고 배경 텍스처 증강을 쓰는 쪽으로 판단합니다.

2-4. 바닥 밝기·색 (주색)
[ ] 밝은색(흰/아이보리/밝은 회색) [ ] 중간(베이지/밝은 나무) [ ] 어두운색(진한 나무/검정/진회색)

💡 왜? 물체와 배경의 휘도 대비를 계산해서 대비 강화(CLAHE/감마)를 어느 방향으로 걸지 정합니다.

2-5. 바닥 오염도 (먼지·머리카락·부스러기)
[ ] 깨끗함 [ ] 약간(머리카락 몇 가닥) [ ] 많음(먼지뭉치·부스러기 다수) [ ] 반려동물 털 많음

💡 왜? 미세 잡물이 많으면 작은 물체 오검출이 늘어나므로 형태학적 필터, 최소 객체 크기 필터, Hard Negative 수집 범위를 정합니다.

3. 가구 밑 공간 (주 탐색 영역)
3-1. 가구 하부 틈 높이 (가장 낮은 진입 대상 기준)
[ ] 10cm 미만(진입 불가) [ ] 10～15cm [ ] 15～25cm [ ] 25cm 이상 / 실측: ____cm

💡 왜? 틈이 낮으면 화면 위쪽이 가구 바닥면으로 가려지므로, 쓸모없는 상단을 잘라낼 ROI 크롭 비율을 정합니다.

3-2. 가구 밑 깊이 (안쪽 끝까지)
[ ] 50cm 미만 [ ] 50～100cm [ ] 100cm 이상

💡 왜? 깊을수록 LED 빛이 멀리서 약해져 화면 안 조도 차이가 커지므로 비네팅/조도 불균일 보정이 필요한지 판단합니다.

3-3. 가구 밑 내부 구조물 (복수 선택)
[ ] 비어 있음 [ ] 가구 다리·프레임 [ ] 전선·멀티탭 [ ] 수납 박스 [ ] 먼지 뭉치

💡 왜? 구조물이 많을수록 가림(occlusion)이 늘어나므로 Cutout/부분 가림 증강의 비율을 정합니다.

4. 대상 물품 특성 (물품별로 반복 기록)
4-1. 물품 종류 (복수 선택)
[ ] 에어팟/무선이어폰(본체) [ ] 이어폰 케이스 [ ] 반지 [ ] 귀걸이 [ ] 열쇠 [ ] 리모컨 [ ] 기타: ____

💡 왜? 클래스마다 크기 분포가 크게 달라서 입력 해상도, 타일 크기, 앵커/스케일 증강 범위를 정하는 출발점이 됩니다.

4-2. 물품 실제 크기 (가장 긴 변)
[ ] 1cm 미만(귀걸이 침) [ ] 1～3cm(반지·이어버드) [ ] 3～7cm(케이스·열쇠) [ ] 7cm 이상(리모컨)

💡 왜? 실제 크기와 카메라 거리로 화면 속 픽셀 크기를 역산해 타일링이 필요한지 정합니다.

4-3. ⭐ 화면 속 물체 픽셀 크기 (로봇 높이에서 촬영, 1m 거리 기준)
[ ] 16px 미만 [ ] 16～32px [ ] 32～64px [ ] 64px 이상 / 촬영 해상도: ____ × ____

💡 왜? 전처리 설계에서 가장 중요한 수치로, 리사이즈 비율, 타일 크기와 겹침(overlap), 업샘플링 여부를 바로 결정합니다.

4-4. 물품 색과 바닥 색의 대비
[ ] 높음(예: 흰 에어팟 + 진한 마루) [ ] 중간 [ ] 낮음(예: 흰 에어팟 + 흰 타일, 은반지 + 회색 바닥)

💡 왜? 대비가 낮으면 색 공간 변환(LAB/HSV 채널)과 국부 대비 강화를 우선 적용해야 합니다.

4-5. 물품 표면 재질
[ ] 무광 플라스틱 [ ] 유광 플라스틱(에어팟) [ ] 금속 광택(반지·열쇠) [ ] 보석/투명 소재

💡 왜? 광택이나 금속 재질은 LED 아래에서 하이라이트가 포화되므로 노출 상한 설정과 Saturation clipping 처리가 필요한지 판단합니다.

4-6. 물품이 놓이는 자세 (현장 재현 결과)
[ ] 주로 일정(바로 놓임) [ ] 랜덤(뒤집힘·옆으로 섬) [ ] 일부 가려짐(가구 다리·전선 옆)

💡 왜? 자세가 다양하면 회전·원근(Perspective) 증강의 범위를 넓게 잡아야 합니다.

5. 방해 물체 (오검출 유발 요인)
5-1. 대상과 비슷한 물체 (복수 선택)
[ ] 흰 알약/사탕 [ ] 병뚜껑 [ ] 단추 [ ] 동전 [ ] 머리끈/실핀 [ ] 장난감 부품 [ ] 반려동물 사료 [ ] 콘센트·전선 플러그

💡 왜? Hard Negative 데이터를 수집하고 라벨링할 범위, 그리고 다중 프레임 검증의 신뢰도 임계값을 정하는 근거가 됩니다.

5-2. 방해 물체 빈도
[ ] 거의 없음 [ ] 방당 1～3개 [ ] 방당 4개 이상

💡 왜? 빈도가 높으면 confidence threshold를 높이고 연속 확인 프레임 수(N)를 늘려야 합니다.

6. 카메라·주행 조건 (시제품 또는 대체 카메라로 측정)
6-1. 카메라 장착 높이 / 하향 각도
높이: [ ] 3cm 미만 [ ] 3～5cm [ ] 5～8cm
각도: [ ] 수평 [ ] 10～20° 하향 [ ] 20° 이상 하향
💡 왜? 원근 왜곡 정도에 따라 IPM(버드아이뷰) 변환이나 거리별 스케일 보정이 필요한지 정합니다.

6-2. 렌즈 화각 / 왜곡
[ ] 일반(90° 이하) [ ] 광각(90～120°) [ ] 초광각/어안(120° 이상, 직선이 휨)

💡 왜? 왜곡이 크면 가장자리 물체가 찌그러지므로 Undistort(캘리브레이션) 단계를 넣을지 결정합니다.

6-3. ⭐ LED 점등 시 화면 상태 (가구 밑에서 촬영)
[ ] 균일함 [ ] 중앙만 밝고 가장자리 어두움(비네팅) [ ] 가까운 물체·바닥 하얗게 날아감 [ ] 바닥 반사로 빛 번짐

💡 왜? 비네팅 보정 맵, LED PWM 밝기 상한, 노출 고정이 필요한지 판단합니다.

6-4. 주행 중 영상 흔들림 / 모션블러 (예정 속도로 밀며 촬영)
[ ] 선명함 [ ] 약한 블러 [ ] 심한 블러·젤로 현상(롤링셔터)

💡 왜? 블러 프레임 필터링(Laplacian variance), 디블러, Motion Blur 증강을 넣을지 정합니다.

6-5. 바닥 단차·이음새 진동
[ ] 없음 [ ] 타일 줄눈/마루 이음새 약간 [ ] 문지방·러그 경계 있음

💡 왜? 진동으로 프레임이 튀면 영상 안정화나 프레임 선별 로직이 필요합니다.

6-6. 렌즈 오염 가능성
[ ] 낮음 [ ] 먼지 많은 바닥(렌즈에 먼지 붙음) [ ] 반려동물 털

💡 왜? 렌즈 오염 상태를 감지(전체 대비 저하)하거나 Haze/뿌옇게 보이는 증강을 넣을지 판단합니다.

6-7. 카메라 모듈
[ ] Camera Module 3 Wide(수평 102°, 롤링셔터, 오토포커스) [ ] Global Shutter Camera(+광각 렌즈) [ ] 기타: ____ / 출력 해상도: ____ × ____

💡 왜? 화각이 물체 픽셀 크기·ROI 크롭 값을 정하고, 롤링셔터 여부가 LED 줄무늬·젤로 대응을, 오토포커스 여부가 초점 고정 설정 필요성을 정합니다.

💡 왜? 모델은 Hailo NPU에서, 전처리는 GPU 없이 CPU(Cortex-A76 4코어)에서 돌기 때문에 NPU 성능과 CPU 여유가 온보드에 둘 필터를 결정합니다.

💡 왜? 프레임당 전처리 시간 상한(예: 10fps라면 총 100ms 중 몇 ms를 쓸 수 있는지)을 정합니다.

[ ] 없음 [ ] 사람 발/신체 [ ] 얼굴 [ ] 문서·화면 글씨

💡 왜? 학습 데이터를 저장하기 전에 마스킹/블러 처리 단계를 넣어야 하는지 정합니다.

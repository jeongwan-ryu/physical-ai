# MediaPipe 실습 — 손가락으로 숫자 세기

웹캠에 손가락을 펴서 보여주면 **몇 개를 폈는지 세어 화면에 크게 띄워요.** 양손이면 0~10까지 셀 수 있어요.

```
웹캠 프레임 ──▶ [MediaPipe Hand Landmarker] ──▶ 손마다 관절 21개 좌표 ──▶ [우리가 짠 규칙] ──▶ 숫자
                 딥러닝: 손 찾기 + 관절 위치                                거리·각도 계산
```

- MediaPipe는 **관절이 어디 있는지**까지만 알려줘요.
- **손가락이 펴졌는지는 그 좌표로 우리가 직접 계산해요.** ← 이 실습의 핵심

## 동작 원리

### MediaPipe Hand Landmarker (두 단계)

| 단계 | 하는 일 |
|---|---|
| ① Palm Detector | 이미지 전체에서 **손바닥**을 찾아요 (손가락보다 모양 변화가 적어 찾기 쉬워요) |
| ② Hand Landmark | 찾은 손 영역을 잘라 **관절 21개의 3D 좌표**를 예측해요 |

영상 모드에서는 이전 프레임의 손 위치를 이용해 ②만 돌려요. ①은 손을 놓쳤을 때만 다시 돌려서 빨라요.

### 손 관절 21개 번호

```
           8   12  16  20        ← TIP  (손가락 끝)
           |   |   |   |
           7   11  15  19        ← DIP
     4     |   |   |   |
     |     6   10  14  18        ← PIP  (가운데 마디)
     3     |   |   |   |
      \    5---9---13--17        ← MCP  (손가락 뿌리)
       2    \            /
        \    \          /
         1----\--------/
                0                ← WRIST (손목)
```

| 손가락 | 관절 번호 |
|---|---|
| 엄지 | 1, 2, 3, 4 |
| 검지 | 5, 6, 7, 8 |
| 중지 | 9, 10, 11, 12 |
| 약지 | 13, 14, 15, 16 |
| 새끼 | 17, 18, 19, 20 |

### 손가락이 펴졌는지 판단하는 규칙

가장 쉬운 방법은 "손가락 끝의 y가 가운데 마디보다 위면 펴짐"이에요. 하지만 이 방법은 손을 옆으로 눕히면 바로 틀려요. 그래서 **손 방향과 상관없는 3D 거리와 각도**를 써요.

| 손가락 | 규칙 | 기준 |
|---|---|---|
| 검지~새끼 | `손목→끝 거리 / 손목→가운데 마디 거리` | 1.1보다 크면 펴짐 (`EXTEND_RATIO`) |
| 엄지 | IP 관절(3번) 각도가 일자에 가깝고, 끝(4번)이 검지 뿌리(5번)에서 멀리 떨어져 있음 | 150°보다 크면 펴짐 (`THUMB_ANGLE`) |

**처음엔 관절 각도로 판단했다가 거리 비율로 바꿨어요.** 예제 사진에서 측정한 값은 이랬어요.

| | 펴진 손가락 | 접힌 손가락 | 구분 |
|---|---|---|---|
| 관절 각도 | 144~178° | 92~146° | ❌ 겹침 (힘 빼고 편 손가락은 생각보다 많이 굽어 있어요) |
| 거리 비율 | **1.19 이상** | **0.99 이하** | ✅ 확실히 갈림 |

> 좌표는 `hand_world_landmarks`(미터 단위 실제 3D 좌표)를 써요. 화면용 `hand_landmarks`(0~1 정규화 좌표)는 원근과 화면 비율 때문에 왜곡돼서 거리 계산에 맞지 않아요.

### 숫자 깜빡임 막기

손가락을 움직이는 중간에는 값이 순간적으로 튀어요. 그래서 **최근 7프레임 중 가장 많이 나온 숫자**를 표시해요 (`SMOOTH_FRAMES`).

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `finger_count.py` | 실습 코드 (주석에 원리 설명) |
| `hand_landmarker.task` | MediaPipe 손 모델, 약 7.5MB (첫 실행 시 자동 다운로드) |
| `pointing_up.jpg` 외 3장 | `--demo`용 예제 손 사진 (MediaPipe 공식 예제) |
| `runs/` | 결과 이미지 |

## 설치

```powershell
py -m pip install mediapipe
```

> MediaPipe 1.x부터 예전 `mp.solutions` 방식이 없어지고 **Tasks API**만 남았어요. 이 코드는 Tasks API로 작성했어요.
> 인터넷의 옛날 예제(`mp.solutions.hands`)는 그대로 동작하지 않아요.

## 실행

`test` 폴더에서:

```powershell
py mediapipe\finger_count.py              # 웹캠으로 실행
py mediapipe\finger_count.py --debug      # 관절 번호와 판단 값까지 표시
py mediapipe\finger_count.py --demo       # 웹캠 없이 예제 사진으로 테스트
```

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--camera` | `0` | 웹캠 번호. 안 열리면 `1`, `2`를 시도해보세요 |
| `--demo` | 꺼짐 | 예제 손 사진 4장으로 테스트 |
| `--image` | 없음 | 내 사진으로 테스트 (여러 장 가능) |
| `--debug` | 꺼짐 | 관절 번호와 판단에 쓴 값(비율/각도) 표시 |

### 웹캠 창 조작

| 키 | 동작 |
|---|---|
| `q` / `ESC` | 종료 |
| `s` | 현재 화면을 `runs/`에 저장 |
| `d` | 디버그 표시 켜기/끄기 |

### 화면 구성

- **왼쪽 위 큰 숫자**: 펴진 손가락 수 (양손 합계)
- **손목 아래**: `오른손 3` + `엄지○ 검지● 중지● 약지● 새끼○`
- **뼈대 색**: 펴진 손가락은 초록, 접힌 손가락은 회색

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `카메라 0 번을 열 수 없습니다` | `--camera 1`처럼 다른 번호를 쓰거나, 다른 프로그램(줌, 팀즈 등)이 카메라를 쓰고 있지 않은지 확인 |
| 숫자가 자꾸 틀림 | `--debug`로 손가락별 값을 보고 `EXTEND_RATIO`, `THUMB_ANGLE`을 조정해보세요 |
| 엄지가 잘 안 잡힘 | 엄지는 구조가 달라 가장 어려워요. 손바닥을 카메라 쪽으로 향하게 하면 잘 돼요 |
| 손을 못 찾음 | 조명을 밝게 하고, 손 전체가 화면에 들어오게 하세요 |
| `Unable to open file ... hand_landmarker.task` | 한글 경로 문제예요. 이 코드는 모델을 bytes로 읽어 넘겨서 해결했어요 |
| `module 'mediapipe' has no attribute 'solutions'` | 옛날 예제 코드예요. 이 폴더의 Tasks API 코드를 참고하세요 |

## 실습 과제

1. `--debug`로 값을 보면서 `EXTEND_RATIO`를 `0.9` / `1.4`로 바꿔보자. 무엇이 달라질까?
2. 판단 규칙을 "끝의 y < 가운데 마디의 y" 방식으로 바꾸고 손을 옆으로 눕혀보자. 왜 틀릴까?
3. `SMOOTH_FRAMES`를 `1`로 바꾸면 숫자가 얼마나 깜빡일까? `15`로 하면 반응이 얼마나 느려질까?
4. 엄지+새끼만 펴면 `6`(한국식 숫자 표현)으로 인식하도록 규칙을 추가해보자.
5. 숫자에 따라 다른 동작을 하게 만들어보자 (예: 1 → 사진 저장, 5 → 종료).

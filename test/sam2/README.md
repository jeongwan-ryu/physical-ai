# SAM 2 실습 — 가리키면 잘라준다

SAM 2(Segment Anything Model 2)는 Meta가 만든 **범용 분할 모델**입니다.
점이나 박스로 가리키면 그 물체의 **정확한 경계(마스크)**를 잘라주고, 영상에서는 그 물체를 계속 따라가요.

## YOLOE와 무엇이 다른가

| | YOLOE | SAM 2 |
|---|---|---|
| 답하는 질문 | **무엇**이 있나? | **어디까지**가 그 물체인가? |
| 출력 | 클래스 이름 + 박스 (+ 마스크) | 마스크만 (이름은 모름) |
| 입력 | 물체 이름 / 예시 박스 | 점 / 박스 |

→ 둘을 합치면(**YOLOE로 찾고 SAM으로 자르기**) 이름과 정밀한 마스크를 함께 얻어요. (`--mode yoloe`)

## 동작 원리

```
  이미지 ──▶ [Image Encoder] ──▶ 이미지 임베딩 ──┐
             (무겁다, 한 번만)                   ▼
                                          [Mask Decoder] ──▶ 마스크
  점/박스 ──▶ [Prompt Encoder] ─────────────────▲
                                          (가볍다, 프롬프트마다)
```

- 무거운 **이미지 인코더**는 이미지당 한 번만 돌아요.
  - 이 PC(CPU)에서 약 0.65초
- 가벼운 **디코더**는 클릭할 때마다 다시 돌아요.
  - 약 20ms
  - 이 차이 덕분에 실시간 대화형 분할이 가능해요.
- 영상에서는 **Memory Bank**가 이전 프레임의 마스크를 기억해서 같은 물체를 계속 추적해요.

### 프롬프트 종류

| 프롬프트 | 의미 | 결과 이미지 표시 |
|---|---|---|
| 양성 점 (`label=1`) | 여기는 물체다 | 🟢 초록 점 |
| 음성 점 (`label=0`) | 여기는 물체가 아니다 → 마스크 깎기 | 🔴 빨간 점 |
| 박스 | 이 박스 안의 물체 (가장 안정적) | 🟨 노란 박스 |
| 없음 | 이미지 전체를 격자 점으로 찍어 전부 분할 | — |

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `sam2_practice.py` | 실습 코드 (주석에 원리 설명) |
| `sam2.1_t.pt` | SAM 2.1 tiny 모델, 약 78MB (첫 실행 시 자동 다운로드) |
| `bus.jpg` | 예제 이미지 |
| `runs/` | 결과 이미지 (`<모드>.jpg`) |

`yoloe` 모드는 옆 폴더 `../yoloe`의 모델과 텍스트 인코더를 그대로 빌려 써요. 그래서 YOLOE 텍스트 모드를 한 번 실행해 두면 다시 내려받지 않아요.

## 실행

`test` 폴더에서:

```powershell
py sam2\sam2_practice.py --mode click   # ★ 추천: 마우스로 직접 체험
py sam2\sam2_practice.py --mode all     # click·video를 뺀 나머지 전부 (CPU에서 약 2~3분)
```

### 모드

| 모드 | 내용 | bus.jpg 실제 결과 |
|---|---|---|
| `point` | 양성 점 하나 | 찍은 사람 한 명이 통째로 잡힘 |
| `points` | 양성 점만 찍은 결과와, 음성 점을 더한 결과를 비교 | 버스만 찍으면 앞에 선 사람까지 칠해짐 → 사람 위에 음성 점을 추가하니 사람이 빠짐 |
| `box` | 박스 하나 | 박스 안의 사람 분할 |
| `multi` | 점 4개 = 물체 4개 | 사람 3명과 버스가 각각 따로 분할됨 |
| `yoloe` | YOLOE 박스 → SAM 마스크 | person 5, bus 1 정밀 분할 |
| `everything` | 프롬프트 없이 전부 | 마스크 13개, **CPU에서 약 108초** |
| `click` | 마우스로 직접 | — |
| `video` | 영상에서 물체 추적 | — |

### 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--mode` | `all` | 위 표의 모드 |
| `--source` | `bus.jpg` | 이미지 경로 (`video` 모드에서는 영상 경로) |
| `--point X Y` | `283 600` | `point`·`video` 모드에서 쓸 점 좌표 |
| `--box X1 Y1 X2 Y2` | `221 405 345 857` | `box` 모드에서 쓸 박스 좌표 |
| `--classes` | `person bus` | `yoloe` 모드에서 찾을 물체 |

`points`, `multi` 모드의 좌표는 `bus.jpg`에 맞춰 코드에 적혀 있어요. 다른 이미지로 해볼 때는 `point`, `box`, `click` 모드를 쓰세요.

### 예시

```powershell
# 내 사진에서 점 하나로 분할
py sam2\sam2_practice.py --mode point --source "C:\Users\작업용\Pictures\desk.jpg" --point 400 300

# 내 사진을 마우스로 분할
py sam2\sam2_practice.py --mode click --source "C:\Users\작업용\Pictures\desk.jpg"

# YOLOE로 컵을 찾아서 SAM으로 정밀 분할
py sam2\sam2_practice.py --mode yoloe --source "C:\Users\작업용\Pictures\desk.jpg" --classes cup

# 영상 추적: 첫 프레임의 (500, 300)에 있는 물체를 끝까지 따라감
py sam2\sam2_practice.py --mode video --source "C:\Users\작업용\Videos\clip.mp4" --point 500 300
```

## click 모드 조작법

| 입력 | 동작 |
|---|---|
| 좌클릭 | 양성 점 추가 (물체) |
| 우클릭 | 음성 점 추가 (배경, 마스크 깎기) |
| 좌클릭한 채 드래그 | 박스 프롬프트 |
| `r` | 초기화 |
| `s` | 현재 화면을 `runs/click.jpg`로 저장 |
| `q` / `ESC` | 종료 |

클릭할 때마다 터미널에 `디코딩: 20ms | 점 2개 | 면적 31,917px`처럼 처리 시간이 찍혀요. 처음 이미지를 인코딩한 시간과 비교해 보세요.

## 코드 핵심

```python
model = SAM("sam2.1_t.pt")

model(img, points=[[x, y]], labels=[1])                  # 점 하나
model(img, bboxes=[[x1, y1, x2, y2]])                    # 박스
model(img, points=[[x1, y1], [x2, y2]], labels=[1, 1])   # 물체 2개 (점마다 따로)
model(img, points=[[[x1, y1], [x2, y2]]], labels=[[1, 0]])  # 물체 1개에 점 2개
model(img)                                               # 전부 분할
```

> ⚠️ **괄호 깊이에 따라 뜻이 바뀌어요.** `[[x,y],[x,y]]`는 물체 2개, `[[[x,y],[x,y]]]`는 한 물체에 점 2개예요.

결과는 `r.masks.data`(`[마스크 수, H, W]`, 0/1)로 꺼내요.

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| 원하는 것보다 넓게 잡힘 | 빼고 싶은 곳에 음성 점(우클릭)을 추가하세요 |
| 옷만 잡히고 사람 전체가 안 잡힘 | 점 하나는 모호해요. 양성 점을 더 찍거나 박스를 쓰세요 |
| `everything`이 너무 느림 | CPU에서는 정상이에요(약 2분). GPU가 있으면 훨씬 빨라요 |
| `video`가 느림 | 5~10초 정도의 짧은 영상으로 시작하세요 |
| click 창이 안 뜸 | 원격 접속이나 GUI가 없는 환경에서는 창을 띄울 수 없어요 |

## 실습 과제

1. click 모드에서 사람의 **옷만** 클릭하면 옷만 잡힐까, 사람 전체가 잡힐까? 음성 점으로 다듬어보자.
2. 같은 물체를 점 하나와 박스로 각각 분할해 경계 품질을 비교해보자.
3. 코드의 `SAM_MODEL`을 `sam2.1_t.pt` → `sam2.1_b.pt`로 바꿔 속도와 정밀도를 비교해보자.
4. 휴대폰으로 5초짜리 영상을 찍어 `video` 모드로 추적해보자. 물체가 잠깐 가려졌다 나타나도 따라갈까?
